## Limiti della verifica

Non è disponibile un iPhone collegato: gesti, schermate a 375 px con testo ingrandito, VoiceOver, fluidità e fedeltà pixel per pixel restano da verificare sul dispositivo. I test dei componenti verificano vincoli di layout e animazioni con driver simulati, non sostituiscono un rendering nativo.

Google: l’utente ha confermato client Web, origine Cloud Run autorizzata e GOOGLE_CLIENT_ID già configurato nella revisione 00018. Il consenso è In test: possono accedere solo gli utenti di prova. Il consenso reale su iPhone non è stato eseguito. Il tentativo di ispezionare la console tramite Computer Use si è fermato perché l’URL Edge non era verificabile; non sono state eseguite altre azioni nel browser.

Strava: i vecchi collegamenti devono ricollegarsi per le zone. Si mostrano le soglie attuali del profilo, senza inventare distribuzioni di tempo per l’attività. Il consenso reale e gli inviti con account reali restano da provare; i flussi server sono coperti da test HTTP con servizi simulati.

File: limiti dichiarati di 20.000 campioni per attività e 900 kB per documento, per rispettare Firestore. Se superati viene rifiutato l’intero lotto prima di scrivere. Richieste HTTP limitate a 2 MB e lotti client entro 1,8 MB. La cadenza dei file resta nell’unità per minuto della fonte, senza assumere una conversione fra passi e cicli.
